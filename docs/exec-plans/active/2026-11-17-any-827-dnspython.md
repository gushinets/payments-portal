## Upstream decision and reachability

[GHSA-45c3-73f7-pv4m](https://github.com/advisories/GHSA-45c3-73f7-pv4m) / CVE-2026-114605 affects versions below 2.9.0.
[Upstream fix b485e460c266540a1a09ca6d8d1d7b685b1d3023](https://github.com/rthalley/dnspython/commit/b485e460c266540a1a09ca6d8d1d7b685b1d3023)
limits compression chains to 16 pointers. Select available stable [2.9.2](https://github.com/rthalley/dnspython/releases/tag/v2.9.2),
which includes the fix and subsequent upstream security corrections. Its Python >=3.11 requirement supports this API's Python 3.12;
email-validator's installed >=2.0.0 dependency permits it. Targeted uv resolution changes only dnspython and its distribution metadata.
No owning manifest adjustment is necessary.

Installed Pydantic 2.13.4 `pydantic.networks.validate_email` calls the installed email-validator 2.3.0
with `check_deliverability=False`. That validator imports/calls deliverability only behind the enabled flag.
Repository application search found EmailStr in identity registration/login/session output and password-reset presentation;
no direct `dns` import, parser, resolver, or separate email-validator caller was found.
Tests observe the real email-validator invocation and refuse resolver, wire parser, socket construction and address lookup.
The dependency is installed and vulnerable at baseline; no directly exposed affected DNS-parser path or application exploitation is established.
Ordinary HTTP/SMTP host resolution is not evidence of using dnspython's wire parser.

## Execution and evidence

1. Baseline installed from unchanged lock using pinned uv.
2. Added synthetic offline email cases for registration/login/password-reset models: case folding, display names/whitespace,
   IDNA, Unicode NFC, nonexistent but syntactically valid domains, and invalid syntax/domain literals.
3. Bounded child-process parser regression equivalent to upstream's 16/17-pointer fixture. Timeout kills/reaps child;
   no DNS server queried. Baseline: **1 failed, 89 passed**. The 17-pointer case returned the root name instead of rejecting.
   This establishes absent upstream limit, not excessive-CPU timing or production reachability.
4. `uv lock --directory apps/api --upgrade-package dnspython==2.9.2 --python 3.12`, then locked sync,
   using uv 0.12.7 and an explicit checkout-root environment: **PASS**, only dnspython 2.8.0 -> 2.9.2.
5. Patched focused suites: **206 passed** (identity/session, password reset, email verification/delivery and dependency contracts).
   Final committed regression file: **32 passed**; Ruff lint/format and whitespace checks passed.

Initial baseline test invocation used the host's C: temporary directory and hit three unrelated permission errors;
rerun with isolated D: temporary files produced the clean baseline result above. No harness change made.
Docker daemon is available on permissioned execution; no existing containers were running when inspected.
