### 3.2 Contract supported by documentation

Request: `GET /internal/v1/capability-manifest?tenant_id=anytoolai&region=ru`.

Response fields: integer `schema_version=1`, `tenant_id`, `region`, `manifest_version`, `generated_at`; `products[]` contains `product_id` and boolean `enabled`; `usage_metrics[]` contains `metric_key`, `product_id`, `unit` and boolean `enabled`. Valid 200 is complete/all-or-nothing. 401 = missing/invalid service authentication; 403 = unauthorized tenant/region/scope; 5xx = producer cannot produce a valid complete response. User login is not S2S auth. Production requires TLS and no browser access.

The selected product/metric must be enabled for a new binding. Later disablement is not historical paid-access revocation. `manifest_version` changes deterministically on semantic changes, not just a new generation timestamp. Keep simulation metadata outside this Kernel wire schema.
