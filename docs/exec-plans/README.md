# Execution Plans

- `active` contains current executable work.
- `completed` contains finished plans and retained historical records.
- `superseded` contains retained implementation history from a direction that
  must not be continued as the current target.
- `tech-debt.md` records known debt that is intentionally not part of active work.

Plans include the objective, non-goals, agreed decisions, steps, acceptance
criteria and verification methods. Record tested revisions and results in the
PR or a separate verification report.
